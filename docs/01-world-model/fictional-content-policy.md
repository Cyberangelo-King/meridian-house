# Fictional Content Policy

## Purpose

The Meridian House experience uses invented institutional content to make the prototype coherent. This must never be confused with verified client history.

## Treat as fictional unless explicitly verified

- Named projects and engagements
- Client organisations
- Founder biography
- Awards
- Publications
- Partnerships
- Project metrics
- Quotes
- Testimonials
- Professional credentials
- Geographic project history
- Press coverage
- Research findings attributed to Meridian

## Release rule

Before a public launch, each claim must be marked as one of:

1. Verified real-world fact.
2. Approved fictional content.
3. Clearly labelled concept/prototype content.

No invented evidence should be presented as a real credential.
