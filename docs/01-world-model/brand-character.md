# Brand Character

Meridian House should feel:

- architectural
- artistic
- elegant
- intelligent
- precise
- grounded
- contemporary
- culturally aware
- quietly ambitious

It should not feel:

- like a generic consultancy
- like a stock-image architecture firm
- like a software startup
- like a brochure
- like empty futurism
- neon-heavy
- excessively gradient-driven
- dependent on spectacle
