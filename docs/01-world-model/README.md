# 01 — World Model

Meridian House is best understood as **The Cartographer**: a practice that makes complex relationships legible before intervening.

## Meridian

A meridian is a line used for geographic orientation.

For the brand, Meridian represents connection, reference, orientation, and making relationships legible.

**House** is the place where disciplines, ideas, evidence, and people meet.

Working interpretation:

> A place for understanding where things are, how they connect, and where they could go.

“Near perfection” is an internal aspiration, not a public claim.

## Core beliefs

1. A city is not infrastructure. It is behaviour at scale.
2. Technology does not fix broken urban systems. It can amplify them.
3. Foundations determine futures.
4. African cities should be understood on their own terms while learning from global patterns.
5. Good design begins with understanding the system that produced the problem.
6. Every intervention has consequences beyond its boundary.
7. Precision is a form of care.

## Engagement loop

**OBSERVE → MAP → UNDERSTAND → QUESTION → DESIGN → TEST → BUILD / ADVISE → OBSERVE AGAIN**

The last step returns to the first. It is a loop, not a funnel.
