# Requirements

## Functional

- Responsive institutional homepage.
- Persistent minimal navigation.
- Methodology experience.
- Project dossiers.
- Thinking/field-note layer.
- House/institution section.
- Conversation entry points.
- Reduced-motion behavior.
- Keyboard-accessible interactive elements.
- Semantic content that remains meaningful without WebGL.

## Content

Core content entities:

- Project
- Engagement
- Research note
- Proposition
- Method stage
- Discipline
- Person
- Conversation route
- Place
- Topic

## Technical

Prototype target: static HTML/CSS/JavaScript suitable for Netlify.

Production target: component-based frontend with a structured content layer, reusable 3D scene system, performance budgets, accessibility safeguards, and protected editing boundaries.
