# 03 — Decisions

This section records decisions that materially affect the product.

A decision should capture:

- context
- decision
- alternatives considered
- reason
- consequences
- status

## Current decisions

- Institutional rather than founder-led identity.
- Methodology is a central narrative device.
- 3D is subordinate to storytelling.
- Semantic HTML remains the source of truth.
- Fictional content is explicitly governed.
- The prototype starts static for speed and clarity.
- The target architecture can evolve into React/Three.js without changing the underlying information model.
