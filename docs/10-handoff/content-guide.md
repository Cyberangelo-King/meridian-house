# Content Guide

## Voice
Precise, calm, observant, intelligent, culturally aware, confident without exaggeration.

Avoid empty buzzwords, generic “end-to-end solutions” language, unsupported superlatives, invented statistics, fake testimonials, and corporate filler.

## Project writing
Start with the problem and system context, not a list of deliverables.

A project record should make clear:

**What arrived → what was observed → what changed in understanding → what was designed/tested → what evidence exists → what the client can do next.**
