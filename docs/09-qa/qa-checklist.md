# QA Checklist

## Content
- [ ] No fictional claim presented as verified fact.
- [ ] Projects and descriptions approved.
- [ ] Conversation routes clear.
- [ ] No unsupported professional claims.

## Navigation
- [ ] Links resolve.
- [ ] Focus visible.
- [ ] Mobile navigation usable.
- [ ] Dialogs close with Escape.

## Responsive
- [ ] Small phone
- [ ] Large phone
- [ ] Tablet
- [ ] Laptop
- [ ] Large desktop

## Accessibility
- [ ] Keyboard-only pass
- [ ] Heading hierarchy
- [ ] Landmarks
- [ ] Contrast
- [ ] Button/link labels
- [ ] Reduced-motion pass
- [ ] WebGL-independent content

## Performance
- [ ] Images optimised
- [ ] No unnecessary blocking scripts
- [ ] 3D complexity appropriate
- [ ] No obvious layout shifts
- [ ] Console free of avoidable errors

## Security
- [ ] Headers present
- [ ] No secrets in source
- [ ] Third-party dependencies reviewed
- [ ] Future forms have abuse controls
