# Visual System

## Working palette
- Background: deep charcoal / near-black
- Primary text: warm off-white
- Secondary text: muted warm grey
- Rules: restrained dark grey
- Accent: architectural amber/gold

The prototype defines these as CSS variables.

## Typography
Production should prefer self-hosted, explicitly licensed fonts where practical. External font loading should not become a single point of failure.

## Layout
Strong editorial grid, generous negative space, thin rules, compact labels, large declarative headings, restrained cards.
