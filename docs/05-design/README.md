# 05 — Design

The visual language should feel like an architectural institution with editorial intelligence.

## Principles
1. Meaning before spectacle.
2. Spatial hierarchy before decoration.
3. Precision before polish.
4. Motion should reveal relationships.
5. 3D should be useful.
6. Typography should carry information.
7. Empty space is part of the composition.
8. The interface must remain credible at every breakpoint.
