# 3D Direction

## Narrative
**abstract structure → system → city → interconnected systems → observations/questions → interventions/work → invitation**

The object starts abstract and gradually reveals itself as a city/living system.

## Rule
> If removing a 3D element does not reduce understanding, emotion, intrigue, or narrative continuity, it probably does not need to exist.

## Interaction
Scroll changes state. Hover/tap can reveal layers. City states correspond to narrative stages. WebGL is progressive enhancement. Reduced-motion mode remains coherent.
