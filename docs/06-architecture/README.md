# 06 — Architecture

## Current prototype
Static HTML, CSS, browser JavaScript, Three.js via CDN, Netlify static deployment target, no server-side data, authentication, form backend, or secrets.

## Target production
React + Vite or equivalent; Three.js / React Three Fiber; GSAP + ScrollTrigger where justified; optional smooth-scroll layer; GLB assets; structured content source/CMS; static generation where possible; semantic HTML; accessibility fallbacks; performance budgets.

The target stack is a direction, not a reason to prematurely migrate the prototype.
