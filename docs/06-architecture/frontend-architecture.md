# Frontend Architecture

### Content layer
Projects, thinking, people, method stages, places, topics.

### Semantic presentation
Accessible document structure. Meaningful without JavaScript or WebGL.

### Interaction
Navigation, dialogs, scroll state, progressive enhancement, reduced-motion behavior.

### Spatial layer
Three.js scene, camera states, geometry, materials, scene transitions.

### Delivery
Static hosting, caching, security headers, monitoring, deployment automation.

**Principle:** the spatial layer is a view of the system, not the system itself.
